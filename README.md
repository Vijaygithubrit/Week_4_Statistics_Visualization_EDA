# 📊 Week 4 — Statistics, Data Visualization & Exploratory Data Analysis

## 📌 Project Overview

This project was completed as part of the Week 4 Data Analytics assignment.

The objective of this project is to apply statistical analysis, data visualization, and Exploratory Data Analysis (EDA) techniques to a real-world Superstore sales dataset.

The analysis was performed using Python, Pandas, NumPy, Matplotlib, Seaborn, and SciPy.

---

## 🎯 Objectives

The project covers:

- Statistical analysis
- Mean, Median, and Mode
- Variance and Standard Deviation
- Correlation analysis
- Probability
- Outlier detection
- Data visualization
- Data inspection and cleaning
- Exploratory Data Analysis
- Business insights
- Data-driven business recommendations
